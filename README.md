Développeur full-stack TypeScript, à Bordeaux. Formé au développement web, puis à la philosophie et aux lettres classiques, je construis notamment des outils numériques pour l'étude des langues anciennes.

L'essentiel de mon code est publié par l'[Association pour la défense des humanités](https://github.com/defense-humanites), que je préside.

## Projets

- **[Bailly.app](https://bailly.app)** · dictionnaire grec ancien-français en ligne, libre et gratuit ; près de 50 000 visiteurs par mois. Nuxt, TypeScript, API Hono sur Deno, SQLite, IndexedDB. [Code source](https://github.com/defense-humanites/bailly.app)
- **[greek-conversion](https://github.com/defense-humanites/greek-conversion)** · bibliothèque TypeScript de conversion entre grec, beta code et translittération (normes ALA-LC, ISO, SBL, TLG, BnF). Sur [npm](https://www.npmjs.com/package/@humanities/greek-conversion) et [JSR](https://jsr.io/@humanities/greek-conversion).
- **[humanites.fr](https://humanites.fr)** · site de l'association, construit avec Astro.

## Outils

TypeScript · Vue.js, Nuxt, Astro · Node.js, Deno, Hono · SQL (PostgreSQL, SQLite), IndexedDB · Tailwind · Docker
